# GW_EnergyPilot
GoodWe ETA EnergyPilot is an unofficial Home Assistant integration for advanced control of GoodWe ETA hybrid inverters. It provides direct battery power control, EMS mode management, EMHASS-based optimization, grid import and export control, and optional EV charging coordination.
