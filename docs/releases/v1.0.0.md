# GW EnergyPilot v1.0.0

**Channel:** Stable

GW EnergyPilot v1.0.0 is the first production release on the protected v1
release contract. It promotes the current single `gw_energypilot` Home
Assistant integration without creating a second domain, config entry or HACS
repository.

## Included changes

- Adds a seven-day, 4096-event EMHASS-to-GoodWe execution ledger with wanted
  and actual SOC, plan/strategy evidence, write outcome and refreshed GoodWe
  mode/setpoint verification. The dashboard shows the nearest ±6 hours and a
  full 48-hour history plus conditional 24-hour projection.
- Adds Recorder-based source-attribution estimates in detailed Battery · Plan ·
  Price views and preserves the wanted-SOC snapshot that applied at each
  historical controller decision.
- Shows verified EV anti-discharge periods on the same canonical execution
  history: solid underlays for discharge blocking and striped underlays for
  explicit charging permission. Intervals never bridge a Home Assistant
  restart and unverified commands do not produce a span.
- Corrects generic Battery Strategy wording so the dashboard does not present
  installation-specific capacity as universal behavior.
- Keeps the connectivity detail popover above surrounding cards and isolates
  pointer handling from the live dashboard beneath it.
- Introduces tag-only stable/beta publishing. Stable `v1.x.x` tags must match
  the exact `main` head; beta `v1.x.x-beta.N` tags must match the exact `beta`
  head. GitHub prereleases are never Latest and normal HACS users remain on
  stable releases unless they explicitly opt in.

## Compatibility and safety

- EMHASS remains an external prerequisite and the canonical plan owner.
- GoodWe register definitions, EMS mode semantics, setpoint-before-mode write
  order, entity unique IDs and device identity are unchanged.
- Existing installations need no migration. The new optional execution Store
  starts empty and fills only with future controller decisions.
- Source-attribution labels are visualization estimates, not settlement-grade
  accounting and never feed Automatic Control, EMHASS or persistent grid
  accounting.
- Execution history is diagnostic evidence only. Failure to persist it never
  changes controller success or causes a GoodWe command.

## Installation

Normal HACS users install or update to v1.0.0 from the regular GW EnergyPilot
repository entry and restart Home Assistant when prompted. Leave the
repository's prerelease switch off to continue receiving stable versions only.

Testers who later want beta builds can explicitly enable the HACS prerelease
switch for GW EnergyPilot or select a published `v1.x.x-beta.N` in the
repository version picker. Turning prereleases off again changes future update
selection; it does not automatically downgrade an installed beta.
