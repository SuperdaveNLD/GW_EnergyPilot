# GW EnergyPilot v1.3.0-beta.6

**Channel:** Beta prerelease

**Status:** Beta; automatic mode-2 field validation remains pending.

## Hybrid 2.0 Beta

Select **Settings → GoodWe → Automatic control strategy → Hybrid 2.0 Beta**
to use maximum grid assistance with PV priority in EMHASS net-charge windows.
An explicit battery charge plan below its deadband and grid import above its
deadband select mode **2** at the configured **Maximum control power**, capped
at 15,000 W. DC PV can contribute on top of that AC assistance.

EV start preserves this command. Neutral/discharge plans during EV charging
remain mode 8 Hold. Other plan steps use existing Hybrid behavior. Missing or
non-ready optimizer output, persistent-plan fallback and EV-stop freshness
retain the existing rules.

The new mode follows planned charge windows rather than planned amplitudes;
actual charging and SOC can exceed the forecast, including its planned maximum.
It requests an allowance, not guaranteed import. Inverter/BMS limits remain
in charge. See [policy and qualified hardware evidence](../HYBRID_2.md).

No existing strategy is changed or automatically migrated. Manual modes stay
exact, Automatic Control OFF returns mode 1/0 W, and the strategy does not
change charger controls or the separately opt-in EV load balancer. No new
registers, entity IDs, config-entry migrations or persistent stores are added.

The existing command sensor adds a strategy attribute for the permanent Lit
explanation. The complete frontend cache boundary advances to `1.3.0-beta.6`.
