# GW EnergyPilot v1.3.0-beta.11

**Channel:** Beta prerelease

**Status:** Beta; new opt-in Hybrid 3.0 strategy, field validation pending.

## Hybrid 3.0 excl. EV — designed around Tibber Grid Rewards

Let Tibber independently choose when the EV charges, without intentionally
using the home battery to compensate that EV grid draw. The house may still
use PV/battery and planned battery charging can continue. This is the design
objective, not a reward guarantee or a guarantee of zero transient EV feed.

| Intent | Without EV | With EV |
|---|---|---|
| Self-use / neutral | **1 — Auto** | **5 — measured house excl. EV** |
| Directed discharge | **3 — planned discharge watts** | **5 — measured house excl. EV** |
| Directed charge | **2 — planned grid assistance + PV** | **2 — same allowance, unchanged** |

The existing grid deadband still selects self-use first; neutral battery
plans also select self-use. There are no mode-9/10 net-only branches in this
new strategy. Mode 2 keeps the planned watt magnitude; it does not force
15 kW charging. Available PV may add to actual battery charging.

## More explicit EV recovery and readback

- Mode 5 uses fresh local total load minus measured EV, on the existing
  15-second callback. Both reports must be ≤30 seconds old and ≤15 seconds
  apart. Missing required data selects Hold; recovery needs at least 15 seconds
  and two distinct fresh pairs. Valid directed charging remains mode 2.
- After an automatic write, obtain bounded direct local EMS readback instead
  of relying on a debounced full telemetry refresh. An unconfirmed Hold write
  invalidates the old mode-5 acknowledgement. No new registers or charger writes.
- Keep the native EV-stop Hold until a new successful optimization and both
  fresh live plan outputs. Existing manual ownership and valid plan resilience
  remain authoritative.
- The full execution history and diagnostic report identify measurement ages,
  hold/recovery reason and command confirmation. A mismatch or failed readback
  is no longer hidden behind the generic EV-override label.
- English/Dutch strategy explanations, the six-scenario dashboard table and
  mode-2 grid-assistance target labels use permanent telemetry-patched UI.

## Install and select explicitly

Enable prereleases for GW EnergyPilot in HACS, install **v1.3.0-beta.11** and
restart Home Assistant. Then select **Settings → GoodWe → Automatic control
strategy → Hybrid 3.0 excl. EV**. Existing users are not switched automatically;
Hybrid 2.0 and all other strategies remain available. Stable stays unchanged.

No EMHASS settings, 700 W CUSTOM forecast, SOC profiles, identifiers, Store
keys or versions are migrated. Full policy and test/field boundaries:
[Hybrid 3.0](../HYBRID_3.md).

Software validation is separate from physical acceptance. Mode-5 surplus-PV
behavior, the EV/external-PV/local-load boundary, transient response and actual
Tibber reward impact still require synchronized field evidence. Prior captured
mode-5/Hold oscillation has not been proven physically eliminated.
