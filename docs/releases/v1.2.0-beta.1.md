# GW EnergyPilot v1.2.0-beta.1

**Channel:** Beta prerelease

This prerelease combines the permanent mobile control modernization with the
selectable SEMS+ Beta telemetry source on top of stable v1.1.1.

## Mobile control modernization

- Battery actions, Automatic Control, EMHASS strategy, Battery Strategy,
  Optimize, Custom SOC and manual EMS controls now live in one permanent
  declarative Lit component tree.
- Controls remain connected during telemetry, plan, language, layout and
  Settings updates. Selected state follows confirmed Home Assistant/backend
  publication rather than an optimistic click.
- Pending duplicate activations, reordered responses, failures, keyboard/focus,
  native touch scrolling and one thousand telemetry updates are covered by the
  dedicated desktop Chromium, iPad WebKit and iPhone WebKit gates.

## SEMS+ Beta telemetry

- Configuration → GoodWe data & control can select Local Modbus TCP or SEMS+
  API Beta telemetry and configure a write-only password, station, inverter and
  60–300 second cloud cadence.
- Authentication supports SEMS+ cross-login, regional gateways, one token
  renewal and bounded rate-limit back-off. Ambiguous identities, stale/future
  samples, unsupported station shapes and sentinel values fail explicitly.
- Only the evidence-backed PV/load/grid/inverter/battery subset is mapped.
  Cloud lifetime counters and missing meter phases do not impersonate local
  register data.

## Safety and compatibility

- Local Modbus remains mandatory and is the only transport for every EMS mode,
  setpoint and verified minimum-SOC write/read-back.
- Cloud telemetry and local-control health remain independent. A success on one
  path never marks the other path fresh or reachable.
- Existing config entries remain on Local Modbus unless explicitly changed.
  Entity unique IDs, device identity and persistent Store keys are unchanged.
- Physical iPhone/Companion and live SEMS+/GoodWe field acceptance remain
  required before stable promotion.
