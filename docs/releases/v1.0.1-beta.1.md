# GW EnergyPilot v1.0.1-beta.1

**Channel:** Beta prerelease

This opt-in beta combines the compatibility fixes for issues #110 and #111 on
top of the unchanged v1.0.0 control, persistence and release contracts.

## Included fixes

- Normalize supported integral wall-clock optimization cadences stored by an
  older configuration as numbers such as `15.0` or strings such as `"30.0"`.
  The selector receives its canonical `15` or `30` value and the options form
  can open and save normally. Unsupported fractional values remain invalid.
- Keep the existing Optimize now and EMHASS cost-function button text nodes
  when a live telemetry patch produces the same label. This prevents WebKit
  from losing the delayed native click between pointer-down and pointer-up.
- Extend the real-browser regression to hold both affected controls through
  rapid telemetry updates and require one service action, zero label-child
  mutations, stable control/main identity and zero full renders on desktop
  Chromium, iPad WebKit and iPhone WebKit.

## Compatibility and safety

- GoodWe register definitions, EMS modes, setpoint-before-mode write ordering,
  Automatic Control decisions and manual control ownership are unchanged.
- EMHASS remains external and retains plan/configuration ownership.
- Entity unique IDs, device identity, persistent Store schemas, accounting and
  dashboard history data are unchanged.
- The interval fix does not silently round unsupported fractional values.

## Installation

This build is offered only to HACS users who explicitly enabled prereleases for
GW EnergyPilot or deliberately select `v1.0.1-beta.1` in the repository version
picker. Normal users remain on the latest stable release. Restart Home Assistant
after installation when HACS requests it.
