# GW EnergyPilot v1.3.0-beta.10

**Channel:** Beta prerelease

**Status:** Beta; opt-in Hybrid 2.0 charging change, hardware validation pending.

## Hybrid 2.0 charges in mode 2

Directed charging outside the grid deadband now selects **mode 2 instead of
mode 11**, both with and without an independently charging EV. The existing
bounded `abs(P_batt)` setpoint is retained, capped by Maximum control power
and 15,000 W. It is now a PV-priority grid-assistance allowance, not a fixed
battery-power target. Available GoodWe-visible PV can add to battery charging,
so actual charging power and SOC may exceed the EMHASS forecast. Inverter and
BMS limits remain authoritative. This does not restore beta.6/beta.7 maximum
dispatch and does not add measured PV to the commanded setpoint.

Grid-first branching, exact deadband boundaries, EV house self-use/Hold,
readiness and freshness gates, scheduling and persistent identities remain
unchanged. Manual mode numbers remain exact, including mode 11. Battery,
Grid and original Hybrid strategies are unchanged. The CUSTOM load forecast,
EMHASS configuration and independent EV charging schedule are not modified.
No new control loop, register or charger command is introduced.

The controller, read-only preview and future execution history use the same
mapping. English/Dutch explanations and the complete frontend cache boundary
are updated to 1.3.0-beta.10.

## Installation and limits

Enable prereleases for GW EnergyPilot in HACS, select **v1.3.0-beta.10**, install
and restart Home Assistant. Keep **Hybrid 2.0 Beta** selected if this is the
intended automatic strategy. Existing settings and history are preserved.
This release is not Latest; stable users remain on the stable channel.

Synchronized automatic mode-2/PV/EV field validation remains required.
Mode-5 PV-surplus behavior and the local-load/EV/external-PV measurement
boundary also remain open. This release does **not** fix the separately
reported delayed read-back/EV-stop issue or repeated mode-5/Hold transitions.
See [the current decision matrix and evidence](../HYBRID_2.md).

## Validation

Regression coverage includes mode 2 with and without EV, planned watt caps,
zero dispatch, grid-first boundaries, legacy strategies, exact manual modes,
the shared preview and transition from an old mode-11 read-back. Release
gates require Quality, HACS, hassfest, the frontend architecture audit and
desktop Chromium / iPad WebKit / iPhone WebKit checks on the final candidate.
Automated tests verify software behavior, not physical inverter performance.
