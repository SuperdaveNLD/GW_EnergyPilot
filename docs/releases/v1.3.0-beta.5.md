# GW EnergyPilot v1.3.0-beta.5

**Channel:** Beta prerelease

## EV protection preserves the selected strategy

Starting EV charging no longer replaces a Grid/Hybrid charge plan with mode 11
when the grid target is neutral, exporting or unavailable. Explicit battery
charging follows the same normal strategy mode and setpoint as without EV.
Discharge and neutral battery plans still select mode 8 Battery Hold.
Missing required grid data waits without a write; EV-stop fresh-plan protection
and the persistent-plan fallback remain intact.

For the supplied 13:00 plan, Hybrid still requests mode 9 at 9,574 W: this fix
does not turn a grid-import strategy into a 15 kW battery-charge command.
Battery strategy requests mode 11 for that battery plan. The guard uses planned
battery direction; PCC/Auto actual direction remains dependent on local balance.

No entity IDs, options, stores, register definitions or EMS write order change.
Existing EV status/overlay command labels are reused. Frontend version and cache
boundary advance to `1.3.0-beta.5`; no rendering or interaction logic changes.

## Validation and rollout

Prepared candidate, not published. Local validation passed:

- Python compileall and all 519 unit tests;
- all 35 JavaScript commands from the Quality workflow;
- repository validation and the beta.5 release contract;
- desktop Chromium, iPad WebKit and iPhone WebKit browser matrix (zero failures).

HACS and hassfest must still be green on the final release head.
Hardware validation of EV start/stop, mode/setpoint readback and actual battery
direction in modes 1/9/10 remains required; pasted telemetry is prior-version
evidence, not a hardware test of this candidate.
