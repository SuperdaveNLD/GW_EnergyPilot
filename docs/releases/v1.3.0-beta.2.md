# GW EnergyPilot v1.3.0-beta.2

**Channel:** Beta prerelease

This beta makes Power overview responsive at dashboard-card level and adds an
optional EV charger visualization without changing energy accounting or
control semantics.

## Responsive Power overview

- Power overview now offers `S`, `M` and `L` controls in its window bar.
- Small occupies one dashboard column, Medium two columns and Large the
  complete row. Narrow mobile layouts safely collapse every choice to one
  column.
- The flow diagram chooses compact geometry from its measured card width, so
  house, grid, battery, PV and charger nodes remain aligned when the card is
  placed in a narrow column.
- The selected size is retained in the existing browser-local dashboard layout
  preferences.

## Conditional EV charger branch

- A charger node appears only when at least one EV charger source is configured.
- When a finite configured charger-power value is available, the node displays
  it in watts. Otherwise it reports active charging or an unavailable value.
- The charger branch is presentation-only and is explicitly shown as part of
  total household load. It does not alter canonical grid accounting, household
  load calculations, anti-discharge decisions or charger load balancing.
- Direct power-entity updates refresh the display even when Automatic Control
  is off; no additional actuation path is introduced.

## Compatibility and safety

The existing compact EnergyPilot controls, scoped flow-motion preference,
localized help, stable telemetry DOM and bounded iOS click recovery remain in
place. Expanded control disclosures now stay above the red, amber and green
card-window controls, and the non-interactive `AUTO ACTIVE` badge is
substantially smaller without reducing operational touch targets. GoodWe
registers, EMS mode/setpoint signs and write order, EMHASS plan
ownership, Battery Saver policy, entity unique IDs, config-entry identity and
persistent Store schemas are unchanged.

Stable v1.2.0 remains the normal/latest production release. This beta is
available only to users who explicitly enable prereleases for the HACS
repository.

## Validation

The release is validated with Python compilation, the complete repository unit
suite, repository invariant validation and the desktop Chromium, iPad WebKit
touch and iPhone WebKit touch stability matrix. Browser coverage verifies all
three Power overview sizes, saved layout preference, narrow/full-width
geometry, conditional charger visibility, live charger-power updates and
unchanged `main` identity during telemetry patches.

The complete active frontend graph uses cache boundary `1.3.0-beta.2`.
