# GW EnergyPilot v1.2.0-beta.7

**Channel:** Beta prerelease

This prerelease is a validated roll-forward of v1.2.0-beta.6. It keeps the
complete mobile-control fix set unchanged and publishes it under a new
immutable version and frontend cache boundary.

## Retained mobile behavior

- the root-scoped adapter waits 120 ms for a native touch click before using
  the same element's existing `.click()` path;
- movement beyond 12 px, pointer cancellation, secondary touches and disabled
  or disconnected targets remain rejected;
- one late physical click after fallback remains deduplicated;
- Battery · Plan · Price `S/M/L`, `12h/24h/36h`, expand/footer and execution-
  history open/close controls retain minimum 44 × 44 CSS-pixel touch targets on
  coarse-pointer or narrow displays;
- numbered Beta Tests remain local diagnostics and cannot call Home Assistant,
  GoodWe or EMHASS.

## Compatibility

GoodWe register handling, EMS mode and setpoint semantics, EMHASS ownership,
Battery Saver profiles, entity unique IDs and persistent stores are unchanged.
Stable v1.1.1 remains the normal/latest production release.

## Validation

The release must pass compile, unit, repository, HACS and hassfest validation
plus the desktop Chromium, iPad WebKit touch and iPhone WebKit touch regression
matrix on the exact published commit.

The complete active frontend graph uses cache boundary
`1.2.0-beta.7-chart-touch1`.
