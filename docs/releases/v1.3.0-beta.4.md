# GW EnergyPilot v1.3.0-beta.4

**Channel:** Beta prerelease

This beta fixes missing solar-production curves in the default Battery · Plan ·
Price graph. Beta.3 restricted them to Large and expanded views, leaving the
usual Medium graph without either curve or its legend.

## Solar production in every chart size

**S, M, L and expanded views** now display both solar-production series:

- solid yellow: actual combined PV production from Recorder;
- dashed yellow: expected solar production from the validated EMHASS plan.

Both legend entries and their solid/dashed swatches are present in every size,
including the expanded graph outside the dashboard. The normal graph also explains
when actual or forecast data is unavailable. Existing data sources, GoodWe
control, EMHASS ownership, entity identifiers and persistent stores are unchanged.

The complete frontend cache boundary is `1.3.0-beta.4`. Install this prerelease
through HACS, restart Home Assistant and reload the EnergyPilot dashboard.

## Validation

The browser regression covers both solar paths and legend entries while
switching through all sizes and opening the expanded graph on desktop
Chromium, iPad WebKit and iPhone WebKit. Repository Quality, HACS and hassfest
checks remain release gates.
