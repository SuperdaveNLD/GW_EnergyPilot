# GW EnergyPilot v1.2.0-beta.2

**Channel:** Beta prerelease

This prerelease keeps the permanent mobile control surface and selectable
SEMS+ telemetry introduced in beta.1, then adds three bounded field fixes and
diagnostics.

## SEMS SOC safety and diagnostics

- The observed transient SEMS `soc: 0` placeholder is no longer accepted as a
  real battery measurement.
- EnergyPilot falls back from `powerflow.soc` to the selected inverter's
  positive SOC. If neither value is usable, SOC becomes unavailable and an
  EnergyPilot-owned EMHASS solve is rejected instead of starting at 0%.
- Dashboard settings -> **LOG** records a credential-free allowlist of raw SEMS
  values, mapped values and SOC source/rejection decisions. Account, password,
  API token and arbitrary portal fields remain excluded.

## Wanted SOC interval timing

- EMHASS `SOC_opt` represents the state reached after applying the associated
  power interval. Battery · Plan · Price therefore plots Wanted SOC at the
  validated 15/30/60-minute interval end rather than one slot early.
- New execution evidence stores the same immutable `soc_opt_target_at` instant.
  Battery power, grid power and price timestamps keep their existing meaning.

## Local mobile interaction diagnostics

- The dashboard layout menu adds **Beta tests**, an isolated local laboratory
  with native button, switch, select and slider variants plus raw event/action
  counters.
- The page sends no Home Assistant service or WebSocket call and no GoodWe or
  EMHASS command. Closing or clearing it has no operational effect.

## Safety and compatibility

- Local Modbus remains the only owner of EMS and verified minimum-SOC writes
  and read-back; SEMS remains telemetry-only.
- Existing entity unique IDs, device identity, config entries, Recorder history
  and persistent Store keys are unchanged.
- The complete frontend graph uses cache boundary
  `1.2.0-beta.2-soc-end-sems2-beta-tests1`.
- Physical SEMS/GoodWe and iPhone/Companion acceptance remain required before
  stable promotion.

## Validation evidence

- 482 Python unit and regression tests passed.
- Python compile, repository validation and the `v1.2.0-beta.2` release
  contract passed.
- The complete JavaScript graph passed syntax and targeted model, delegated
  control and Dutch-localization checks with the bundled Node.js runtime.
- The frontend stability matrix passed with no failures on desktop Chromium,
  iPad WebKit touch and iPhone WebKit touch, including the SEMS settings,
  interval-end Wanted SOC and 20-action Beta-tests controls.
