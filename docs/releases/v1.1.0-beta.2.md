# GW EnergyPilot v1.1.0-beta.2

**Channel:** Beta prerelease

This hotfix restores dashboard configuration saves for installations that have
selected a managed Battery Strategy profile.

## Fixed

Selecting a managed profile stores an internal
`battery_saver_soc_limits_managed` ownership flag. The dedicated dashboard
settings API previously passed that flag into the generic EP/EMHASS options
schema, which correctly rejected the unknown key and displayed:

```text
extra keys not allowed @ data['battery_saver_soc_limits_managed']
```

The settings API now separates both dedicated Battery Saver options before
generic validation and restores them unchanged after the regular options have
been converted. EP and EMHASS settings can therefore be saved without losing
the selected profile or its SOC-limit ownership.

## Compatibility and safety

- Existing config-entry options remain valid; no migration is required.
- The selected Battery Strategy profile and managed ownership are preserved.
- No GoodWe register is read or written by this settings-save fix.
- EMHASS policy, optimizer ownership and automatic-control semantics are
  unchanged.
- Entity unique IDs, device identity and persistent Store keys are unchanged.
- All features and compatibility guarantees from v1.1.0-beta.1 remain active.
