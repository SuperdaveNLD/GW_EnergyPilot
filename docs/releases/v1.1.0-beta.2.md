# GW EnergyPilot v1.1.0-beta.2

**Channel:** Beta prerelease

This prerelease validates the managed-profile dashboard settings-save hotfix
that is promoted unchanged in v1.1.1.

## Fixed

The dashboard settings API now separates both dedicated Battery Saver options
before generic EP/EMHASS schema validation and restores them unchanged after
the regular options have been converted. EP and EMHASS settings can therefore
be saved without losing the selected profile or its SOC-limit ownership.

## Compatibility and safety

- Existing config-entry options remain valid; no migration is required.
- No GoodWe register is read or written by this settings-save fix.
- EMHASS policy, automatic control, entity identities and persistent Store
  keys are unchanged.
