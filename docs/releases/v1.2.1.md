# GW EnergyPilot v1.2.1

**Channel:** Stable

This release makes every active energy route immediately readable. Each finite
active connector now carries one moving round energy ball, including the
external AC/PCC PV route. The old directional arrows are removed because the
ball already communicates direction clearly.

## Live-flow behavior

- one energy ball moves in the physical flow direction on every active route;
- external PV uses the same movement and intensity contract as internal PV,
  battery, grid, house and EV routes;
- low, medium and high power retain their existing relative line thickness and
  use a matching particle speed and glow;
- finite idle routes show a stationary quiet dot;
- unavailable routes remain dashed with their existing unknown-state marker;
- `prefers-reduced-motion` keeps particles stationary.

Particle and state nodes are preserved across ordinary Home Assistant telemetry
updates. The stable-DOM, native scrolling, permanent Lit controls and bounded
iOS missing-click recovery contracts remain unchanged.

## Compatibility and safety

The release changes presentation only. GoodWe register definitions, EMS write
order and signs, EMHASS ownership, Battery Saver policy, entity unique IDs,
device identity and persistent store keys are unchanged. The complete active
frontend graph uses cache boundary `1.2.1-stable1`.

The release is gated by Python compilation, the complete unit-test suite,
repository validation and the desktop Chromium, iPad WebKit touch and iPhone
WebKit touch stability matrix.
