# GW EnergyPilot v1.2.0-beta.4

**Channel:** Beta prerelease

This prerelease adds isolated, local-only activation-method comparisons for the
physical iOS Home Assistant Companion behavior observed on app build 2026.2805.
It does not apply a pointer workaround to operational EnergyPilot controls.

## Five clean test methods

Dashboard layout → **Beta tests** now starts with five numbered buttons:

1. native click without live diagnostic rerender;
2. direct pointerup on the target button;
3. delegated pointerup on the diagnostic component;
4. native click with a 120 ms pointerup fallback;
5. immediate pointerup with a 700 ms late-click deduplication window.

Each method records pointer, click and completed-action counts plus the action
source. A pointerup method accepts only a primary pointer that moved no more
than 12 px. It neither captures pointers nor prevents native scrolling.

## Observer-neutral measurement

Raw events, values and action counts are buffered without changing reactive Lit
state during pointerdown, pointerup or click synthesis. The visible display is
updated after 650 ms of inactivity. The JSON export reads the live buffers and
therefore remains current even before the display catches up.

The previous eight native button, switch, select and range controls remain under
**Oude acht controletests tonen** for optional comparison. The complete page is
local browser state: it has no Home Assistant action gateway and cannot send a
service, WebSocket, GoodWe or EMHASS request.

## Compatibility and cache

Operational controls, GoodWe/EMS semantics, EMHASS behavior, entity IDs, device
identity, config entries and persistent Store keys are unchanged. The complete
active frontend graph uses cache boundary `1.2.0-beta.4-touch-methods1`.
